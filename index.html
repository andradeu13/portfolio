Process

How I work

Every case follows the same design-thinking chain, so a decision on screen can always be traced back to a pain point and a principle.

01EmpathizeInterviews, personas, empathy maps and the real context of use.
02DefinePain points by stage of the journey, written as “How might we…”.
03IdeateCustomer journeys, flows and decisions tied to UX principles.
04PrototypeUI built on a system of tokens and reusable components.
05TestA plan to measure each decision, with metrics and experiments.

Design systems

Consistency is a product feature

A design system is how a product stays coherent as it grows. In my cases it shows up as tokens, components with states and written rules that explain when to use each one.

  • Iguana Panel: color, shape, 4/8 spacing and type tokens, and a rule that change is never shown by color alone.
  • Haru: the same cards and type in Home, Insights and Plan, with mixed radii to separate actions from content.
  • Le Petit Paradis: repeatable patterns for product, cart and checkout across mobile and desktop.
